# Culpeper matching results

`aggregate.py` collects candidate evidence. `evidence.jsonl` retains source rows; `candidates.json` and resolved-name files hold candidate and taxonomic results; `geography.json` and `eligibility.json` record subsequent decisions. See [matching rules](../MATCHING_RULES.md) and [eligibility rules](../ELIGIBILITY_RULES.md). All identifications remain hypotheses.
