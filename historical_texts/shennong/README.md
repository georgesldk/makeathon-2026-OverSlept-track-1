# Shennong Bencao Jing

`extract_sun.py` creates `entries.json` from Sun Xingyan and Sun Fengyi’s 1799 reconstruction. It separates the reconstructed classic from later textual layers. `bretschneider.py` matches entries to the historical reference and `bretschneider_ids.py` extracts and checks proposed identification quotations. See [data sources](../../DATA_SOURCES.md), [eligibility rules](../../matching/ELIGIBILITY_RULES.md) and [review status](../../README.md#open-issues). Names and translations require expert interpretation.
