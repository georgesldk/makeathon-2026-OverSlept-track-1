## What was tested
The paper's experts compared Dioscorides' description of each plant with modern flora descriptions (Flora of Turkey, Flora of Cyprus) of each candidate plant, detail by detail, and scored each detail good / partial / no match / absent (data file 9, 1,213 scored details). We gave the same details to AI models and compared their scores with the experts'. "Absent" (the flora says nothing) is set by code, not by the model, exactly as the experts did; the model judges only the details both texts describe.

Sample: 15 candidates, 5 for each expert verdict (strong, moderate, weak), drawn at random (seed 42) from candidates with at least 4 judged details and a Greek chapter that matches the paper's reference.

## Notes and limits
- The English runs use the paper's own extraction of Dioscorides' details (Beck's translation), so they measure comparison only. The Greek run also tests finding the detail in Wellmann's Greek, which is what our pipeline must do.
- The verdict uses our reading of the paper's method (group means, congruence = positive − negative groups); the same code scores experts and models, so the comparison is like for like.
- Temperature 0. Each reply is stored in `cache/<run>/` with the model version Google reports.
- Source: Lardos A, Patmore K, Allkin R, Lazarou R, Nesbitt M, Scott AC, Zipser B (2024). J Ethnopharmacol 322:117622. https://doi.org/10.1016/j.jep.2023.117622 (CC BY 4.0). Data: https://figshare.com/s/2e0f64b5794892ed4679
